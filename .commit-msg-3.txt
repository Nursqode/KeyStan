feat(desktop): build a Windows installer, and a script for sessions without the MSI service

* nativeDistributions now carries what an installer needs: vendor, copyright, description, and a
  stable upgradeUuid, so that 1.2.0 replaces 1.1.0 instead of being installed beside it. The MSI
  installs per user - no administrator prompt - and adds a Start-menu entry and a desktop shortcut.
* build-msi.ps1 produces the same MSI where jpackage cannot. WiX's ICE validation fails whenever the
  Windows Installer service is unreachable - a sandboxed build, a service account, some CI runners -
  with LGHT0217 and jpackage exits 216, even though WiX itself is fine. The script takes jpackage as
  far as its generated wixobj files, unpacks WiX 3.11 from the Compose plugin's own cache if asked,
  and links with light.exe with the validations suppressed. ICE validation only checks an installer;
  it does not build it.
* README.md and README.ru.md describe both routes, and the release carries a ready MSI.
