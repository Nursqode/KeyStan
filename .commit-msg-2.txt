feat(desktop): add a Russian interface and Russian documentation

The window now ships two text catalogs and follows the system language by default, with an explicit
choice in Settings.

* core:ui gains the Strings catalog: an interface with English and Russian implementations, so a new
  string is a compile error in every language until it is translated. Counted nouns go through
  Russian plural rules - "1 логин", "2 логина", "5 логинов" - which a single interpolated string
  cannot express.
* The catalog travels in AppState, so a language change is an ordinary state update that recomposes
  the window: no composition locals, no re-created subtrees, and no parameter threaded through every
  screen.
* Every screen, dialog, status message and vault failure is localized. A failed AEAD tag keeps its
  own wording, because "wrong passphrase" is the only failure that means that.
* The preference is stored in settings.json and defaults to SYSTEM.
* Six tests cover the catalogs: a reflection-based completeness check over the whole interface
  (an empty translation fails the build), the plural forms including the teens, and the vault-error
  mapping.
* README.md and desktop/README.md gain a language switcher, and README.ru.md and
  desktop/README.ru.md are full Russian translations. Version 1.1.0.
